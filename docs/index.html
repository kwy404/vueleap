Stop 1: Scan

Scan the whole project

  • Only reads files. Nothing runs, nothing is uploaded.
  • SFCs, JSX and TSX, TypeScript, script setup and class components.

Questions

Before the leap

Something else? Open an issue on GitHub.

Is it safe to run on my code?

Yes. By default vueleap only reads files. --fix prints a diff and writes nothing unless you add --write, and it never touches files outside the project folder. The demo on this page runs in your browser and sends nothing anywhere.

What does it rewrite, and what does it leave to me?

Pure renames are rewritten: lifecycle and directive hooks, keyCode modifiers, .sync, $scopedSlots, transition classes, @hook: events and productionTip. Everything else gets a finding with the line, an explanation and the official guide. That is 8 of the 41 checks.

Does it support TypeScript, script setup and class components?

Yes. Single file components with lang="ts", TSX, Vue 2.7 <script setup> and vue-property-decorator class components are analyzed. Pug templates are skipped with a warning.

Can I use it from code?

Yes. analyze(dir) and fix(dir) work on a project, and analyzeSource(code) and fixSource(code) work on one file in memory, in Node or in the browser.
