Vue 2 end of life

Vue 2 reached end of life on December 31, 2023. Apps keep running, but they no longer get fixes from the Vue team, and more of the ecosystem only supports Vue 3 every month.

Official announcement: Vue 2 end of life

What end of life means in practice

  • No security fixes for Vue 2 itself from the core team.
  • Libraries move on: vue-router 4, Vuex 4, Pinia, Vuetify 3, Element Plus and most new libraries target Vue 3 only.
  • Tooling moves on: modern build tools, test utilities and IDE support focus on Vue 3.
  • Hiring and knowledge: documentation, examples and new developers use Vue 3.

A low risk plan to migrate

  1. Measure: npx vueleap --html report.html lists every breaking change and Vue 2 only dependency.
  2. Run on Vue 3 early with the @vue/compat migration build, using the flags vueleap prints.
  3. Apply safe fixes with npx vueleap --fix --write, then fix the remaining findings rule by rule.
  4. Upgrade router, store and UI libraries.
  5. Remove compat flags and gate CI with npx vueleap --fail-on error.

The step by step migration guide covers each step in detail.

Frequently asked questions

When did Vue 2 reach end of life?

Vue 2 reached end of life on December 31, 2023. Vue 2.7 was its last minor release.

Is Vue 2 still supported?

Not by the Vue core team: Vue 2 no longer receives updates, including security and browser compatibility fixes. The official end of life page points teams that need continued fixes to a commercial third party offer (HeroDevs Never-Ending Support), but the ecosystem has moved to Vue 3.

Will my Vue 2 app stop working?

No. Published versions keep working. The risk grows over time: unpatched vulnerabilities, browsers and build tools moving on, and libraries dropping Vue 2 support.

What is the fastest way to know how much work the upgrade is?

Run npx vueleap in the project. It lists every Vue 3 breaking change with file and line, the Vue 2 only dependencies, and an effort score.
